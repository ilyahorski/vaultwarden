# Roadmap: Aetheria: The Cat’s Codex

## 🏛️ Архитектурная Фаза (Миграция)

### Рефакторинг систем (Приоритет: Высокий)
- [ ] **Data Layer (Dexie.js)** — Внедрить IndexedDB для хранения:
  - Состояния мира (405x302 ячеек)
  - Прогресса 200 слотов инвентаря
  - Глобальных флагов сюжета (Story Flags)
- [ ] **Duo Character System** — Удалить старые классы (Warrior/Mage/Rogue). Реализовать статы и развитие для:
  - Героини (Physical/Tools)
  - Кота (Magic/Lore)
- [ ] **Inventory 2.0** — Система на 200 слотов с категоризацией в React UI:
  - Фильтры: Оружие, Свитки, Одежда, Еда, Квестовые

### Редактор и Метаданные (Logic Mapping)
- [ ] **Visual Metadata Editor** — Добавить в `TilesetPicker` интерфейс для разметки свойств тайлов (passable, type) без правки кода.
- [ ] **Entity Layer** — Реализовать размещение NPC и Врагов как объектов, а не просто тайлов, с сохранением в `CellData`.
- [ ] **Time-Shift Engine** — Механика подмены слоев `Past/Present/Future` в `EditorMode` и `WorldScene`,   - Реализовать слои: `Past`, `Present`, `Future`
  - Синхронизация коллизий Excalibur при смене эпохи.

## 📜 Сюжет и Геймплей

### Нарратив
- [ ] **Dialogue Engine** — Система диалогов в React 19:
  - Поддержка веток (choices)
  - Условия проверки флагов (например, "кот заговорит только после нахождения книги")
- [ ] **Event Triggers** — Размещение невидимых актеров в Excalibur для запуска сцен при входе в область.

### Прогрессия
- [ ] **Skill Trees** — Деревья навыков для дуэта:
  - Героиня: Археологические инструменты, выносливость.
  - Кот: Магия Эфира, обнаружение секретов.
- [ ] **Essence Quests** — Логика сбора 3-х эссенций (Прошлое, Настоящее, Будущее).
